# P1 模拟任务基础：审核记录

类别：官方机制实现修复 / 本地测试工具。依据 R07/R08、任务书 §五/§5.3/§六、接口 §1.1/§1.7/§2.1。官方原件未修改。

## 变更与意义

1. 错误及部分正确答案保留任务，返回 errorCode=2，不提前发放奖励；更好的答案可继续提交。超时/离开/死亡只结算一次历史最高通过率；超时返回 errorCode=1。旧模拟器“提交任意答案即结束”的报告不能继续作为新判题语义的证据。
2. 修正机房 fixture 正文固定 A3、答案却随机选择其他房间的内部矛盾。此项是本地题库修复，不是官方题目更新。
3. 任务提交记忆原样保存答案，避免改写 JSON 字符串内连续空格、换行等。旧求解器的“首行提取”仍未被完整多轮 Agent 替代，本修复不宣称已经解决全部答案格式问题。
4. 显式安装的本地题库包含文档发现、城市参数查询、接口路径/参数变更、精确小数汇总。标准答案手工列举；Agent只见公开题目和命令结果，题库环境在模拟器私有状态内。
5. 虚拟沙盒只解释 pwd/ls/cat 和已声明的参数化查询程序；不会运行宿主 shell、任意 Python、网络或打开宿主文件。支持非零退出、超时/判题错误/截断注入，结果使用 lastCmdResult 外壳。它是测试替身，绝不是完整官方沙盒实现。
6. 本地 adapter 跨回合递交结果；没有明确虚拟环境的旧场景继续报告沙盒未接入。新题库默认关闭，安装方法为 local_task_cases.install(state, case_ids)。

## 验证范围

tests/test_taskworld_feedback.py：独立两字段标准答案，0%→50%→100%，较差答案不覆盖最佳答案，超时/死亡/离开、幂等、JSON运输、双方 simulator.step、JSON严格字段类型、原样答案记忆，以及真实领取→文档/查询回执→判分链路。

tests/test_local_task_sandbox.py：虚拟目录/文档发现、变更参数和接口路径、Decimal汇总、错误后更正、不允许宿主执行、UTF-8输出截断和官方外壳、两侧数据隔离。

这些确定性测试证明环境和控制通道能支持后续 Agent。手工指定命令驱动的环境测试不等于模型自主解题成功；真实模型成功率、完整任务 Agent、SOP、新闻和多日宝藏仍待后续阶段。全套冻结源码回归通过：Python3.11.10、530 tests、262.312秒；运行前后源码和测试哈希完全一致。结果与文件哈希见本目录 validation.json，摘要见 full-suite-summary.txt。基于已发布34f838a与本目录记录的候选文件哈希，尚未叠加DSH P0b。

## 保留的边界

- 字段级/JSON/精确文本是本地可选判分器，不能推断官方每道题都按同一算法判分。
- 本轮保留既有整数分数处理和 deadline 临界轮规则；平台若提供更精确边界需独立核对。未宣称所有模拟计分已与官方同步。
- 部分作答现在持续占用任务窗口，本地策略得分可能与旧模拟结果不同。旧版本非法提前结算的收益不是需要保持的基准。
- 新能力不改变比赛连接/响应超时，不调用外部 LLM 做同步压缩，不扩大正式观测。
- 无内网/官方 PASS。交付包及源码版本以最终集成清单为准，此工作树本身不是已发布包。
