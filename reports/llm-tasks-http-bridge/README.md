# 外部响应结算入口验证

类别：模拟器/验证工具；依据R01/R07及LLM_TASKS_HTTP_VALIDATION.md。
新增step(..., external_response=...)接收完整官方响应，仿真只结算该响应，
不运行本地策略、消费第二份模型回执或生成本地预览；默认自动模拟路径不变。
外部Agent维护自己的上下文，模拟器的planner字段不伪装为该上下文。

3个独立用例通过：采铜结算且禁止本地策略、公共观测→外部Agent→模型/虚拟工具→独立任务判题、
无效及混用响应拒绝。模型为公开prompt驱动的脚本；无宿主机Shell执行。
完整703项测试通过，Python3.11.10，运行前后源码哈希一致，证据见validation.json。
该报告仍是入口/回归验证；实际压缩包HTTP时延和连续对局另行执行，不能混作同一结果。
