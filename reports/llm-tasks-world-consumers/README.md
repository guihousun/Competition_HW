第一场取消提前备料与完全取消寻宝取得相同结果，定位到提前备料带来的路径/经济连锁变化；
第二场取消提前备料则丢掉宝藏并减分。不能通过永久关闭备料来代表“完善多日宝藏”。
新闻建议与备料也存在交互：第一场取消新闻建议仍能取得宝藏，第二场则没有改变结果。
只有两个定向场景，不能将这些数字外推成总体因果效应或胜率。

下一步只优化可解释的取舍：时间尚未知时，若附近已可领取的任务到达成本不高于买齐材料的时间，
先做该任务；利用任务冷却或远点移动期间备料。仍保留材料、真实路径、回防和全队预算限制，
不利用本地祭坛答案、未来日期或未公开得分。
