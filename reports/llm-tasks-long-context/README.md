# 长上下文与原文检索

内部架构/策略功能，R01/R07。新EvidenceMemory仅保存本题已收到的原文；没有宿主文件、网络或未来观测读取。TaskAgent schema2、TeamAgent schema3，未知旧结构保守降级，需要新对局初始化。

模型可提出inspect(source_id, offset, length, query)：按字符范围读取或定位逐字片段。每次最多2000字符，每题最多8次本地检索；不发executeCmd、不消耗沙盒操作数或普通LLM额度。检索后的新模型请求仍按共享router计数。

每来源最多保留131072字符，总量196608字符，最多12个来源；题目原文优先保留。工具原文经已关联回执进入记忆，摘要裁剪和上游原本截断分开记录。淘汰内容明确显示不可用，不能假造文件引用。换题清空原文、焦点和工具证据；条件化方法库仍须新文档指纹核验。

提示词提供原文索引和有界摘要，检索结果成为下一次请求的重点上下文；聚焦内容在JSON恢复时重新与保留原文核对。普通任务继续运行原有角色调度，模型不生成官方动作字典。

8项独立测试通过，包括长题中部口令恢复、超过摘要上限的文档查询、JSON恢复/摘要篡改、跨题隔离、上游截断与内存淘汰。测试使用脚本化模型请求inspect，不把这些结果宣称为真实模型的平均长题成功率。

Python3.11.10全套693项通过，固定源码哈希见validation.json。新增两项模式测试证明任务Agent与WorldAgent可独立启用，便于全局消融；配置应在新对局开始前固定，不将开关当游戏观测字段。
