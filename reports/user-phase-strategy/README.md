# 单人三火炮：可上传测试候选

2026-09-21。类别：策略优化、配置及调试工具。依据 [R01/R02/R03/R04/R06/R07](../../docs/DEVELOPMENT_RULES.md)，官方攻击范围、冷却、伤害、资源价格和动作额度没有随本次策略调整。当前几何仍依赖已登记的本地建造区域假设，不能当作官方地图认证。

## 本版行为

三座 rocket 优先共享一个合法空位，固定炮手按公开冷却轮流开火，一人一轮只操作一座炮。白天提前到位，其他角色避开共同位；黄昏闲置角色分步让出必要通道，采购预算检查不再删除炮手的合法回防移动。第四天起全员夜防，白天继续任务、采矿、交易和建设。维修工白天按真实报价准备物品，夜间低血量修墙，收到库存下降及成功回执后确认消费。

实际可编辑配置为根 [strategy.json](../../strategy.json)，说明见 [STRATEGY_TUNING.md](../../docs/STRATEGY_TUNING.md)。默认升级目标 `111 → 122 → 222`、维修进场 55%、退出 85%、储备 2 包。它们是策略目标及阈值，不是官方数值、更不是每场已经达成的等级。修改后重启本地服务，比赛平台必须重新打包上传。

## 仍未解决

1. 主炮手死亡、复活后的交接，以及多个角色互堵，仍可能阻止共同位到达。优先最低 ID 存活工人的策略是当前实现选择；不能宣称“整场始终原地三炮”。已有占位者让位与单闲置角色让路，不等于任意多角色局面都已解决。
2. 夜间已经位于另一内圈分区时，替补只能安全操作身边的炮，不出墙绕路。两名工人都死时不让开拓者冒充常态炮手。
3. 维修原岗位长期被占时可能等候；金币、采购路径、存活情况也可能使升级达不到目标。seed1 两边最终炮级分别为 `211` 和 `221`，并未实现目标 `222`。
4. seed1 红方末段工人死亡导致失去火力，基地被毁。该候选未证明优于原参赛策略；本地 1000+ 分不能与公司真实得分直接比较，也不是官方或内网 PASS。
