# 真实新闻返回暴露的维度消费错误

2026-09-15；原候选45557d7501ff644f65b82367293f19ef6bc8e85b，Python3.11.10，OpenRouter deepseek/deepseek-v4.1-flash/max（xhigh），输出预算16384。固定公开新闻，通过真实planner/router/JSON，未调用比赛沙盒。非内网PASS。

三次独立真实请求各调用模型一次。原结果依次 **通过、失败、通过（2/3）**，原返回/完整检查保留在real-1/2/3，文件哈希见manifest.json。

第2次模型正确地将铁矿“第2～3天停产、第4天恢复”和“同期价格上涨、幅度未知”分成两条记录。后者availability=unknown，意为没有对能否开采作出声明。消费层原all(unavailable)却把它当成否决禁采的理由。

修订设计：明确可用性声明独立判断；至少有一个unavailable且不存在相反声明、日期冲突或资料缺口时禁采。价格事实的缺省availability不构成反证。unknown自身也不产生禁采。

证据：before-tests.log记录手写反例在原实现失败；修订副本102项新闻回归通过（shadow-report.json/tests.log），尚未据此声称生产文件已改。replay-1/2/3逐字节重放上述三次真实返回，要求输入prompt也相同，三次全部通过。**重放实际API调用数为0**，不得将其包装成三次新真实调用。修订副本的模块哈希记录在报告里，其他运行模块沿用455。
