## 模式与边界

- baseline：关闭 TaskAgent/WorldAgent，基础策略照常执行；旧 LLM 请求有意不回答。
- tasks：开启 TaskAgent、关闭 WorldAgent；脚本模型只读取本题公开观测与已执行工具结果。
- all：同时开启两类 Agent；新闻/宝藏模型仍是公开证据驱动的脚本响应。
- all-faults：每第 7 次模型请求注入坏响应，每第 5 条命令注入超时。

因此 baseline 比较只说明接通认知通道后的本地差异，**不能宣称相同模型条件下击败原策略**。
本表是同一模拟器下的单队本地积分，不是官方胜率、真实模型能力或内网 PASS。
未知固定刷怪坐标、完整双队结算等原有差异未因这些通过结果消失。
