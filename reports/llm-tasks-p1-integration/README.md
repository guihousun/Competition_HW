# P1 队伍Agent接入与模拟器链路

2026-09-15，类别：策略/内部架构，以及R07任务截止边界实现修复。基线cbca4c6。没有修改官方原文或规则数值，未宣称内网通过。

## 已实现

TeamAgent持有按代际隔离的TaskAgent、当前工具证据与按队伍隔离的SkillLibrary。任务求解器priority40位于关键词10和旧LLM50之间。等待、停止、待判题时返回hold，不回退到旧LLM求解器猜答案。

默认关闭，COMPETITION_HW_TASK_AGENT=on时自动使用共享router。通道提案经仲裁真实发出才确认次数；submitAnswer在最终动作中出现才记提交。工具回执在planner入口经过request归属及原文哈希核对后交给控制器，原文不会被router的短预览替代。工具结果保留长度/哈希/截断标志，方法库不保存答案与历史参数值。

JSON保存/恢复包含控制器、请求映射、证据和方法库；损坏或跨队存档不能成为证据。新对局清除控制器。诊断报告可见阶段、操作次数、证据/方法数量和停止原因，不输出隐藏推理过程。

## 验证

- Python3.11.10完整unittest：**661项通过**，exit0，固定源码，233.562秒；哈希见validation.json。
- 9项独立Agent集成测试：实际brain调度、文档/查询/原样答案、错误反馈重试、错token隔离、普通新闻抢占与正确记账、显式停止、关键词快路径、存档/预览隔离、deadline边界。
- 2项模拟器验收测试覆盖7次任务：三组题分别在challenger/defender运行，共6次；另一次先错答，再从实际错误码2纠正，在同一任务内成功结算。查询路径/参数和答案格式分别变化。
- 每个正常用例3次脚本化模型调用、2次实际虚拟工具执行；成功后由taskworld真实结算并核对奖励。脚本回复只证明集成控制和结算，**不证明真实模型能自主求解**。

## 真实模型与剩余工作

真实OpenRouter deepseek/deepseek-v4.1-flash/max实验通过LocalLLM异步适配器启动，单独最多24次调用、3个任务；模型返回前暂停本地游戏回合。写本报告时原首个请求仍在运行，因此没有真实模型集成PASS结论，也没有重复派发请求。完整日志待实验终态后另行归档。

审核还发现：router当前按相同命令内容去重，会阻止同一任务内有意重新读取相同文件/重试相同查询。应在原冻结实验结束后加入单次操作的幂等标识及独立回归，再比较方法复用前后效果。
