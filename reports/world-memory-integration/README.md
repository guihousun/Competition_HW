## 8d7c279 的实际重复试验与后续修复

`normalized-real-4/5/6` 保留冻结 8d7c279 上的三次完整记录，分别调用 4/3/4 次，结果 **2/3 通过**。第 6 次模型给出了正确结论，但同一来源中略有不同的引文被去重逻辑识别为两个旧候选，更正未同时消除它们。
