## 已验证组件

- TaskAgent独立控制器：提案与实际发送确认分离；验证模型JSON关联和证据引用；命令/回答互斥；提交后等待判题；错误后重试；router过期事件恢复；损坏状态显式降级。没有外部LLM、Shell或官方额度调用。
- 按天环境：显式local_world_news.install后，三天分发地点/用品/时间；停矿两天、收购价变化与恢复作用于真实本地collect动作和vendorShopList。具体文本、6金币测试价和祭坛条件均为本地fixture，不是新官方参数。
- 公共边界：改变未来消息和隐藏祭坛信息不改变当前公开观测和策略决策。默认未安装的场景不变。可从第4天开始同一事件链，验证相对日期没有写死成第1天。

Python3.11.10全套550 tests PASS，用时289.423秒，外层290.219秒；运行前后源码/测试哈希一致，见validation.json和full-suite-summary.txt。测试基线为已发布52cebb3加记录的文件指纹。新控制器8项和按天环境6项重点检查均通过。
