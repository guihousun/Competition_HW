# 多日对照：解释正确之后，行动是否完成

2026-09-15，策略优化/内部Agent，依据R01/R06/R07。模拟器为本地假设环境，不是官方裁判。所有模型解释在这批对照中为依据公开原文的固定脚本；未调用真实API。

## 发现与修复

第一批8次420轮模拟：两张地图、两种阵营，关闭/开启WorldAgent。来源解释正确，但开启组都没有拿到宝藏，总分与各自基线相同。原因是第三天才知道时间，才开始采购，剩余窗口不足以完成商店和祭坛两段行程。

后续允许在公开地点/用品已知、时间未知时先采购，不猜召唤时间：三座武器已存在、基地至少1000血、保留25金币策略缓冲、不打断已发布的自进化任务、真实路径预算允许天黑前回防。购买仍过队伍预算和背包检查。途中的采购动作不会被任务寻路覆盖。这些阈值是可调策略，不是官方规定。
