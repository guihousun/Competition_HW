# 新闻与宝藏证据面板

类别：UI工具；依据路线图P5展示要求，数据权限沿用R01/R07。
基线44d31fa；仅读取当前公开worldNews/vendorShopList和内部WorldAgent已保存的资料与推断。
不读模拟器未来新闻、祭坛私有答案，不改变策略或游戏规则。

新闻分列原文（首次见到的回合、来源ID、截断标记）、模型事件日期与方向、当前观测价。
宝藏分列原文、地点/重复物品/绝对时间窗以及缺失或冲突条件，结构化公开条件另标来源。
新消息尚未解释时标记已有推断可能来自旧资料；未给价格幅度不展示虚构的数值预测。
所有文字以textContent输出；无变化时不重写节点，保留原文滚动位置。

验证：node --check通过，前端稳定性测试通过（包含新证据面板断言）。
实际浏览器8084的脚本world场景：显示第2—3天停铁矿的推断、当前铁价3、
祭坛地点(27,22)及物品/时间未知；截图确认左侧可滚动阅读，右侧仍为主要游戏画面。
浏览器为本地脚本流程测试，不是一次真实模型推理测试。纯UI改动不重复整场基准。
