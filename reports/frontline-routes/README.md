## 改了什么

类别：策略优化与导航实现修复。依据 [开发合同](../../docs/DEVELOPMENT_RULES.md) R01/R02（每角色每轮一动作、八邻移动、真实占用与同时结算）、R03/R04/R06 及任务书§4.4–4.6 的建设、拆除、商品和角色限制。没有修改官方协议、价格、伤害、波次或模拟器结算。

- 从第一天起允许投资到 `333`，有钱且商店/完整行程可行就升级；先补齐二级，再升三级。不再受旧 `111→122→222` 日期上限限制，第四天之后未达标仍继续升级。普通墙损耗不抢炮台升级预算，基地和关键前墙危急时仍救援。
- 城墙升级顺序为前沿中央四堵、前沿两角、其他墙；三级墙退出候选。前六位置永不自动拆除。方位由己方基地和当前来敌方向计算，不写死蓝方坐标；建筑区域仍使用既有 D01 本地假设，未声称官方地图已完全对齐。
- 首日已复现的问题是：采矿路径进入预留炮位时，被另一层逻辑改派回基地，形成成功移动的往返震荡。现改为保留原任务目标，寻找避开炮位的完整路径；该案例有通路，无需拆墙。
- 两工人短期分配不同墙目标；对连续同目标停滞按重新寻路、空闲队友让路、最后受限拆墙处理。只在平静白天、回防时间充足时，允许相邻工人拆己方非前六墙，且必须证明拆后能到当前目标。拆除下一轮确认后才记作通道，默认最多两处，避免反复重建。
- 保留有效采集、交易、任务、维修、开炮动作，夜间在墙内的角色不会为了恢复路线绕到墙外。无解就等待并记录原因，不承诺解决所有多角色冲突。

参数与关闭自动拆墙的方法见 [配置说明](../../docs/STRATEGY_TUNING.md)；验收合同见 [Spec](../../specs/FRONTLINE_UPGRADES_AND_TRAFFIC.md)。
