## 修正

1. 在三炮操控合法、内圈连通、双火箭有共同空操控格的前提下，优先前置火箭，再考虑
   电磁炮位置。左侧基地面向右墙，右侧基地面向左墙；旧炮不强拆，受地形限制时合法回退。
2. 有实际报价的武器升级未完成时，普通墙/基地升级券暂停新购；下一张武器券预算不能被
   其他普通防御消费挪用。紧急基地升级、维修和生命物品保留原条件；已持有券仍可使用。
3. 升级行程可从清晨出发，往返、购买、使用必须在入夜前留 3 轮缓冲，不再被普通工作
   第 55 轮的回防时点打断。白天无可见怪物且两名工人存活时，协调非采购工人留在基地附近，
   不因该工人上一轮暂时离岗就撤销采购。任务/宝藏消费的原有仲裁仍保留。
4. 默认名牌从 152×46 缩为 84×22，约少 74% 面积；身份与完整 ID 保留，细条显示血量。
   有任务时加细进度条；选中/悬停才展开 HP、背包与倒计时。布置标签时避让附近单位和建筑。

## 边界

原先排序武器优先仍会因价格和路程筛选落到墙券；本次明确阻止这种采购回退。无法按时
往返、缺报价、仅一名工人存活时仍可能暂缓升级，不能为了显示升级而加金币或放宽官方规则。
中间候选的自然对局曾未完成升级，日志留在本地版本目录，不作为本版成功证据。
精确机器人 AI、建造区与刷怪点几何等既有待确认项未解除；无内网/官方 PASS。
