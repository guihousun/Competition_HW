# 寻宝与任务调度修复

类别：策略优化；依据 R01/R02/R06/R07，任务书§4.6、§五与接口动作时序。
不改变时间窗、物品、金币、移动速度、任务期限或得分。

发现：已知宝藏的旧调度只检查部分物品可买，距离忽略障碍和购买动作；
在窗口尚未开启且已持有物品时也可阻止任务管线；已运行任务可能被寻宝行程抢走。
完整对局中的得分差还可能来自其他因素，不将本次修复等同于分差的完整解释。

实现要求：
- 保持已发布phaseTask的任务，寻宝不主动抢走其角色；防御主管原有紧急接管不变。
- 统一已知宝藏的行程可行性检查：按背包多重集合计算缺项，全部价格已知且总价不超过队伍可用预算。
- 真实可达的商店/祭坛相邻站位；计入每次购买一轮、移动轮数及召唤所在回合，超过关闭回合则不出发/不购买。
- 未开窗且无需再买物品时不占用任务管线；原有有界提前备料仍保留。
- 不在共用可行性检查中增加白天限制；已知夜间窗口在防御主管允许时仍可召唤，原有白天采购策略不变。
- 独立回归覆盖部分资金、重复物品、到达时已来不及购买/召唤、障碍、已运行任务和未来窗口。
- 冻结来源，比较完整对局与同种子基线；不得通过删掉新闻/宝藏能力来宣称完成优化。
