## 1. 目标与最终取舍

通过固定主责、明确交接和共享预算减少空转。在维持三火炮输出的同时，让尽可能多的人持续产生收益，并在后期靠墙体升级补血与维修包维持防线。

- 工1：墙体维护负责人。白天采矿、卖矿、备墙券和维修包；第3夜起交战时留守修墙。
- 工2：前期主炮手、后期矿工兼第一候补。拓尚未结束任务阶段时夜间操炮；拓实际接班后释放去采矿。
- 拓：前期专注自进化任务；任务机会耗尽后白天接管炮券采购与使用，夜间成为主炮手。
- 三座炮均为火箭发射台，尽量共用一个合法操控格，由一名角色轮换操作。
- 第1–2夜是用户主动选择的经济优先阶段：工1可以直接采矿，即使墙低于40%或炮台受击也不召回。
- 第3夜起工1留守、候补链生效；满足连续2个完整安全回合及路线条件后，再释放额外外勤。
- 已领取的任务不因基地、墙体或炮台告急而主动中断。风险通过接取截止线、工2操炮和第3夜起的工1候补承担。
- 残血墙只在夜间处理；白天不为补血或墙等级目标打断经济工作。健康墙不主动升级，接受等级目标延后。
- 关键前墙已被打毁是另一种情况：白天优先补建到1级，再继续采矿；夜间不能建造。
- 已获准采矿的角色可以跨昼夜延续工作。取消“夜结束前回基地”及其 -4 / 0 回合参数；遇怪先避让、绕路或换矿点，不因怪物靠近就一律回城。
- 物品由实际使用者采购：工1备墙券、维修包和基地券；工2或任务结束后的拓备炮券，不假设背包能直接转交。

这些是策略取舍，不是“前两夜必定安全”或“必定活到第10天”的保证。得分仍按官方任务、击杀及生存结算；不另造奖励。

## 2. 规则来源和不可越过的边界

依据：[任务书](../docs/任务书.md) §4.4、§4.5、§4.6、§4.7、§五、§六，以及[接口文档](../docs/接口文档.md)。

### 用户确认的比赛行为补充

- 自进化类1、类2分别有3次任务机会，合计6次；每次成功都获得对应奖励；失败结束也消耗机会，消耗后不恢复。
- 怪物主要朝基地进攻；角色在3格之外不会吸引它偏航。所有怪物是近程攻击，没有远程怪；同一格可积累多只怪，不排队占位。
- 墙挡住怪物对墙后角色的攻击；己方墙不挡己方子弹。

来源冲突必须保留：现存任务书§4.7.2表格仍写“攻击距离3”，而用户后续明确说明“3格寻敌、全部近程”。迁移时单独登记这一补充，不修改原文，也不再把3格当作远程伤害范围。具体近战格距、并列选敌与结算先后仍需与官方观测核对。

## 3. 三名角色按时段分工

工1、工2是同一局中稳定的身份，不能因一人死亡、复活或暂时换岗而对调名字。阵营读取teamOur；迎敌方向依据实际基地、地图与观测判断，不写死红蓝坐标。

| 时段/阶段 | 工1 | 工2 | 拓 |
| --- | --- | --- | --- |
| 开局及第1–2天白天 | 参与基础建设、采石建一级墙、采矿卖矿；不买墙升级券 | 参与三炮建设、采矿卖矿；负责前期炮券采购和使用 | 优先自进化类2，类2不可用时做类1 |
| 第1–2夜，拓任务阶段未结束 | 直接安全采矿，不等2回合，不因墙低血/炮台受击召回 | 三炮主炮手；提前到岗位，按冷却轮换 | 已接任务继续做；空闲时安全回防准备 |
| 第1–2夜，拓已结束任务阶段并实际接炮 | 继续采矿 | 安全采矿，保留第一候补责任 | 主炮手 |
| 第3天及以后白天，仍有任务机会 | 缺失关键墙先补建；其余时间采矿、卖矿、采购墙券及维修包 | 采矿、卖矿、炮券采购使用 | 继续剩余任务，仍优先类2，遵守动态截止线 |
| 第3天及以后白天，机会全部耗尽 | 采矿卖矿、墙体物资采购，满足预算门槛才买基地券 | 以采矿卖矿为主，减少采购往返 | 接管炮券采购及使用；没有合法需求则安全待命，不代买工1墙体物资 |
| 第3夜及以后，仍有持续受击 | 留守维护墙体；必要时作为第二候补 | 拓尚未接班则操炮；拓稳定接班后安全采矿，异常时召回 | 正在做题则不中断；任务阶段结束并就位后主操炮 |
| 第3夜及以后，额外外勤已获准 | 有低于40%的墙且持有可用工具就先处理；处理完或工具用尽后可采矿/采购 | 按候补状态决定继续留岗或恢复采矿/交易 | 采购、使用道具或在满足条件时处理剩余任务；保留必要炮位覆盖 |

“任务阶段结束”指两类任务机会耗尽、当前任务已结束且没有待关联的模型/沙盒回执。完成其中一道题不等于长期任务阶段结束。当天来不及接下一题时，可以临时回防，不把剩余机会标成耗尽。

表中的第3夜留守约束主要适用于工1；不重新引入“第3夜起所有角色必须回基地”。工2已完成炮位交接后可以继续安全采矿；拓仍在已接任务中时继续解题。

## 4. 工1：墙体维护与补给

### 4.1 前两夜的明确例外

第1–2夜工1以采矿收益为主，不等安全计数；即使关键墙低于40%、炮台正在掉血，也不以这些条件召回工1。前两夜不启用工1的夜间候补职责。

采矿路线本身仍需安全、可达，不能把“不召回”解释成允许走进怪物近战范围。无安全路线时换目标或停在安全点，不向危险格强行移动。

### 4.2 第3夜起维护顺序

1. 有合法炮位补位需求、工2不能及时承担时，工1可暂时接炮；否则保持墙体主责。
2. 只对血量比例 **严格低于40%** 的墙触发夜间升级/维修。恰好40%不触发；不得仍使用旧55%阈值。
3. 紧急例外：侧墙即将被打穿、破口会直接危及工1，而中央墙还能撑住时，先用维修包救侧墙。该例外不允许升级侧墙，也不改变低于40%的夜间处理门槛。
4. 通常目标顺序为：中央最前两堵 → 前方另外两堵 → 前方拐角两堵。同层按血量比例从低到高。
5. 目标可升级且背包有匹配等级的升级券：优先用券，使墙升级并回满血。
6. 没有匹配券、墙已3级或侧墙禁止升级：持有维修包则直接维修，不为了等券拖延。
7. 每次使用后读取下一轮实际血量、等级、物品数量和动作回执；不把“已发指令”当作已经修复。
8. 满血后重新选目标。升级和维修都是一次补满，不需要旧的“修到85%退出”循环。

侧墙保持一级；最后一排墙从开局就不建。已有侧墙通常排在前六墙之后维修，紧急破口例外按上面的第3条处理。无血量低于40%的墙时，夜间不用券升级健康墙。

### 4.3 白天与补给不足

- 第1–2天不购买墙体升级券，只做必要的一级墙建设；工1前两夜经济例外仍生效。
- 白天采矿、卖矿与采购，不因墙残血回城；不主动升级健康墙，也不为了赶墙等级目标打断经济工作。
- 已被打毁的关键前墙，白天由工1优先补建到1级。缺石头先准备合法建造材料；只补需要恢复的关键防线，不趁机修残血墙、升级健康墙或补建禁建后排。
- 第3天起可采购前六墙需要的匹配升级券；**仅在夜间、墙HP严格低于40%时使用**。如果没有降到阈值，就保留券，接受等级目标延后。
- 工1是夜间维修包和墙券的主要持有人。白天采购要把“买到、携带、回到维护站位”作为完整行程。
- 第3夜以后交战未解除时，工具用尽不代表可以擅自外出购物：工1退至基地内安全位置，做炮台第二候补；已持有可用基地券时按§8.3处理，不在墙边无工具空等。
- **已通过2回合额外外勤检查后**：工1先处理有工具可处理的低血墙；全部处理完，或没有可用券/维修包，就可以离开采矿、卖矿和采购。不得无工具却无限等待一堵低血墙。

墙体保护优先于基地道具的机会性使用：工1能阻止会危及自身或打开防线的破口时，先维持墙体；不为了给基地升级跑离正在崩溃的防线。必要的炮手接班仍按§5.3先保证有人操炮。

### 4.4 墙等级节奏的适用范围

用户提供的两队逐日墙数是实战参考，不是照搬的建筑配额；总墙数随日数变化，不能仅凭统计还原具体位置。

| 天数 | 本版可执行的前六墙发展方向 |
| --- | --- |
| 1–2 | 先完成一级前墙与通行布局，不买墙券 |
| 3 | 优先两座中央墙向三级发展，再考虑同组以外的前墙 |
| 4 | 有预算时向4座三级、其余前墙二级推进 |
| 5以后 | 向前六墙全部三级推进，随后重点转为维修续航 |

这些是采购与发展目标，不是硬性达标要求；实际升级还必须满足夜间且HP低于40%。未受足够伤害的墙可以长期低于计划等级，不为“赶进度”提前消耗补满血机会。

**本版不采用的扩展**：早先提到的“第6天8座三级墙”与“前六墙升级、侧面墙保持一级”存在冲突。本版采用前六墙与侧墙一级限制，不挑另外两堵墙升三级；8座三级只保留为对手实战参考，不是当前实施目标。

## 5. 工2：主炮手、采矿与第一候补

### 5.1 主炮手阶段

拓未结束任务阶段时，工2是夜间主炮手。白天仍采矿、卖矿并采购/使用炮券；按实际返程长度提前到三炮公共操控位。

拓已结束任务阶段也不能直接把工2派走：必须观察到拓在合法操控位、能够接管可用火炮，交接完成后再释放工2。每回合一名角色只能承担一个合法动作，不通过同轮走位和操炮制造额外行动。

### 5.2 拓接班后的外勤

工2可以在怪物仍在墙外时采矿，不必等全图无怪，也不因正常城墙承伤自动召回。条件是拓能持续操炮、采矿与往返路线安全。

没有“夜结束前必须回基地”的条件。天亮后继续手头上的采矿，直到采完、需要卖矿、目标失效或出现本角色更高优先级工作。怪物接近时先绕行、换矿点或退到附近安全位置，不把局部避险直接升级成全队回城。

采矿目标优先与工1不同；只有一个可达且有收益的矿点时允许共享，不因为强制分矿而空转。按实际矿价、路径、背包容量和收益判断采卖批量，不等背包彻底装满才卖，也不为未知商品盲目采购。

### 5.3 候补触发与释放

工2停止采矿回防的已确认触发条件：

- 当前炮手死亡、离岗或无法合法操控。
- 炮台实际掉血。
- 存在可以合法攻击的目标及可用炮台，却连续一个完整回合没有合法开火。

“有怪但所有炮均在冷却”“目标不在可用炮射程”“按计划轮换导致某一座未开火”都不属于断火故障。应检查三炮整体覆盖，不能每轮误召回工2。

工2进入候补后，需要拓或其他合适角色已经实际接管，且连续 **3个完整回合** 炮台没有受击、可开火时能正常开火，才允许重新离开；无目标时不要求空打炮。该3回合交接窗口独立于2回合额外外勤窗口。

候补是防止失去操作人，不代表额外角色能直接攻击怪物。拓仍正常操炮时，工2进入安全候补位，不争抢公共操控格、不挤走拓、不假定增加一个炮手就能越过冷却。

第3夜起工2死亡、被堵或不能及时接班时，由工1作为第二候补。工2/拓恢复并完成交接后，工1回墙体工作。正常墙体承伤由工1处理；不得把所有角色同时调走而留下无人炮位。

### 5.4 人员不足时的责任

- 工1死亡或不可用：工2可暂时采购并使用墙券、维修包和基地券；这是由工2自己使用，不通过拓虚构转交。夜间仍必须先保证实际炮位覆盖。
- 只剩一名工人且拓正在任务中：该工人夜间首先保证操炮，不能为修墙同时放弃唯一炮手。两名工人都不可用、拓已接炮时，拓继续开炮，不远行买券。
- 拓已稳定主操炮、仅余一名工人时：第3夜起该工人负责墙体；无工具且满足额外外勤条件才能离开，炮位异常时承担候补。第1–2夜工1的明确不召回例外仍按原约定处理。
- 工人按官方条件复活后，白天优先恢复必要补给与已毁关键防线，再恢复采矿分工；残血墙仍留夜间维护，不因复活增加一个白天维修例外。

## 6. 拓：任务、采购与长期主炮位

### 6.1 任务顺序与机会

- 前两天优先尽快完成两类任务；这只是目标，不假定第二天必然用完6次。
- 自进化类2优先。类2冷却、机会耗尽、不可达或时间不足时，尝试类1；两者均不合适则不接新题。
- 类2一次失败后，下次可领取时仍优先类2；失败本身不触发永久禁做。
- 第3天及以后仍有机会时，白天继续剩余任务，继续受接取截止线约束。
- 每个任务点最多3次任务周期，成功和失败结束都消耗一次；30轮冷却只恢复领取状态，不增加机会。
- 同一次任务内，答案错误但任务未结束，可以根据反馈修正；不能把每次submitAnswer都扣掉一次新的任务机会。
- 每次成功独立奖励；每次结果记录题型、开始/结束、提交、反馈、积分和金币，不用“没有错误码”冒充成功。

### 6.2 动态接取截止线

仅当可用时间覆盖下面整条行程时接新题：

```text
到达任务点 + 领取动作 + 当前任务的可用执行时长
+ 提交/结果确认余量 + 必要岗位交接的路程
```

使用当前公开timeoutRounds，未知时明确记录未知；不得把历史15轮或25轮当作所有任务的固定规则。实现时校准计时口径，避免把提交时间和timeout重复扣减。

这是接新任务前的岗位安排，不是重新加入采矿的固定返程截止线。依据本次计划接班时点与实际防守覆盖判断，不使用已经取消的 -4 / 0 回合参数，不把“夜结束”设为所有角色统一回城时间。

已领取的任务不因防守告急主动中断。保留任务范围与上下文，直到成功、超时或其他实际官方结束条件。工2、工1的候补链承担防守。拓自然死亡或官方判失败属于实际结果，不能伪造为主动完成。

夜间放行后如要接剩余任务，仍要检查完整执行及后续岗位安排；“可以提前工作”不等于忽略任务时长或强行离开正在进行的题目。

### 6.3 任务阶段结束后的白天

拓接管炮券的“采购→运回→使用”完整工作，使工2持续采矿卖矿。金币即时属于团队，不需要工2把金币搬到商店。

无适合购买的炮券时，拓只处理已明确由自己使用、且不影响炮位交接的合法工作；没有此类工作就安全待命。默认不让拓采购墙券、维修包或基地券，避免物资在拓背包里而工1无法使用。采购始终受全队生存预留约束，不为了让拓忙起来买东西。

拓不能采矿、建造或拆墙；能使用升级券、维修包及其他合法道具。但“规则允许使用”不等于“本策略安排拓采购维修”。若已有历史或奖励物品，仍记在实际持有人背包，不折算为工1随时可用的库存。拓担任主炮手时以持续操炮为先，不因工1缺工具就远行采购；任何计划内离岗都须工2实际接班。

新闻和宝藏保留为有证据、有收益且不挤占生存储备与主炮位的机会型工作；不能预先购买未知配方，也不默认追加炸弹、眩晕或召唤令的固定预算。

## 7. 三火炮布局、轮换与升级

- 默认3座rocket；选取三炮八邻域的合法交集作公共炮位。该格须可达、不是建筑/墙/任务点，不占入城通道。
- 布局依据当前地图选择，不复制任一仓库的固定红蓝坐标。公共交集不可用时记录布局失败并选合法替代操控位，不声称已经一人三炮。
- 依据实际冷却、射程和目标每轮选可开火的炮。堆叠怪物按每个机器人计伤害收益，不能按“每格一个怪”估算。
- 三炮升级按**当前最低等级优先**；同级优先中央/主要进攻方向覆盖炮位，再另外两座。几何并列时采用稳定顺序，避免来回改目标。
- 保留“争取第4天前333”的目标；维修库存与低于40%的关键墙优先，资金不够就延后。333不是无条件强制消费。
- 基准价格下三座1级炮全部升3级需要3×(100+150)=750金币，另加初建3×25=75金币；不能把750升级目标当成当前已具备的预算。

### 8.2 预算计算与消费顺序

```text
待补维修包 = max(0, 当夜目标库存 - 已有且可按计划使用的库存 - 已确认本轮采购)
维修资金预留 = 待补维修包 × 当前有效报价
可用于非紧急炮券的钱 = 观测金币 - 本轮已占用支出 - 维修预留 - 已承诺关键墙支出
```

- 第3天起金币不足以同时买维修包和炮券时，**优先维修包**。
- 维修库存之后安排关键墙的匹配升级券与必要白天补建，再用余款升级炮台；基地券在§8.3门槛全部满足后购买。前六墙未达等级目标不是白天使用墙券的理由。
- “已持有匹配墙券先使用”与“采购维修库存优先”不冲突：前者是当前动作选择，后者是金币分配。
- 储备不足时，有多少资金就合法补多少缺口，不设置“未满40金币便一件不买”的门槛。
- 已有库存抵扣采购；物品采购不支持退款，不能重复囤积已经无法使用的升级券。
- 初始建炮和白天必要的损坏炮重建单独处理；保留紧急例外，但“完全无法防守”尚未定义量化条件，不能据此随意花掉储备买升级券。夜间不发build。
- 每轮全队只有一个支出账本，防止工1、工2、拓各自以为同一笔钱可用；采购动作需等待回执确认，不能把计划库存当作背包事实。

第10夜一组墙破、一组未破，并不能证明多4包就是唯一因果；炮火、修墙站位、墙等级和实际怪物聚集同样影响结果。

### 8.3 基地券：工1购买、剩余资金发展

正常购买基地升级券必须同时满足：

1. 当夜维修库存或其采购资金已经落实，不挪用这部分预留。
2. 三火炮已经达到333。
3. 前六墙达到§4.4当前阶段的发展目标；需要的关键防线已恢复。
4. 仍有足够剩余金币、匹配等级的基地券和合法采购机会，且基地未到最高等级。

工1负责“购买→运回→使用”；工1不可用时才由工2兼任。拓正在操炮时继续开炮，不为买基地券离岗。前墙因为不够残血而延迟升级时，接受基地发展的相应延后，不借基地目标反过来强迫升级健康墙。

基地HP严格低于当前等级最大HP的25%记为紧急状态，恰好25%不触发。但这不是绕过上面预算门槛的授权：缺券时不因低血挤占维修预算、停掉必要炮台发展或让炮手远行购物。库存没有可买券也不为此无限空等。

已持有匹配基地券时，工1在合法位置、墙体没有更急迫的破口需要处理、且另一角色已实际覆盖炮位，就可以使用；基地低于25%时及时执行。若当前没有稳定炮手，先由工1接炮，完成真实交接后再用券。一次行动只能做一件事，不假设能同时开炮和升级基地。

## 9. 夜间外勤与安全状态

### 9.1 必须分开的三个放行条件

| 条件 | 适用 | 等待时间 |
| --- | --- | --- |
| 前两夜经济例外 | 工1安全采矿，不被炮台/墙受损召回 | 不等2回合 |
| 岗位交接后的工2外勤 | 拓实际接炮后，工2可采矿；正常墙外战斗不自动召回 | 首次交接按实际占位确认；候补后重新离开须3回合稳定 |
| 第3夜起额外外勤 | 工1等在没有持续受击后提前采矿、采购或其他合法工作 | 2个完整安全回合 + 路线检查 |

2回合安全的计数例子：第N轮建立有效基线，N→N+1安全记1，N+1→N+2安全记2；N+2才能放行。重复请求、网页预览、同一回合多次规划不能增加计数。

安全检查覆盖角色、墙、炮台和基地的HP下降、存活单位消失、观测缺失、新出现的机器人与炮位覆盖。已有机器人可以仍在墙外，只要没有上述受击/失控现象且外勤路线安全；不能继续用“我方目标机器人数量大于0”一票否决。

有怪存在时要保留合法炮位操作人。若确认没有需要覆盖的目标，才按剩余工作与回防时间分配；不得仅因2回合不掉血让所有人同时离开。

### 9.2 正常承伤、异常与计数撤销

- 怪物在墙外正常打墙、拓仍能操炮：工1维修；这阻断全队额外外勤，但**不自动召回已经安全采矿的工2**。
- 炮台掉血、炮手离岗/死亡、可用炮无合法输出：触发工2候补；第3夜起工2无法承担才触发工1补位。
- 工1已通过额外外勤离开后，出现新怪、受击、观测缺失或炮位失控：撤销本次额外外勤，按本夜职责回防。
- 自身路线遭遇怪物时，先停止危险路线并换目标/避险，不能因为没有收到基地警报就继续走进怪群。
- 路线安全至少避免进入3格寻敌范围及下一步可能的近战威胁；移动余量是策略保守量，不改怪物规则。确切余量及路径预测方法留给迁移实现评审。

### 9.3 跨昼夜采矿与局部避让

- 删除采矿的“夜结束前返程”限制及 -4 / 0 回合参数；也不将其改名为风险评分继续影响动作。
- 预测机器人下一步会靠近时，先调整下一步、绕行或换安全矿点；有安全路线就继续采矿，不要求整段行程必须以基地为终点。
- 暂时没有安全路线，选择可达安全等待点或其他合法经济工作；不强行走进3格寻敌区，也不因为路径受阻就反复提交同一失败动作。
- 黎明本身不取消未完成的采矿。按公开观测更新目标、价格、背包和岗位；有本角色更高优先级工作才切换。
- 召回按角色执行：工2按炮位候补条件，工1按第3夜维护职责与额外外勤撤销条件；不能写成“任意友军受击/任意墙低血，所有人都回城”。
- 观测缺失时不启动新的未知风险外勤。已在外的角色先恢复可验证安全的路线或位置；不能把缺失当安全，也不把数据缺失直接等同于必须走回基地。

允许承担路径绕行和收益波动，不允许通过读取未来波次、模拟器私有状态或预测成事实来保证安全。承担风险的策略目标与真实结果分别记录。

当前公开接口未必有完整逐次受击回执。仅比较HP只能叫“未观察到净掉血”，同轮修复可能掩盖攻击。因此安全计数应结合当前威胁几何与实际可用观测，日志中不宣称已证明绝无攻击；缺失数据不当作安全。

## 10. 执行中的冲突恢复与防空转

- 角色先认当前任务/岗位责任，再规划动作；不让通用寻路、购物或采矿逻辑覆盖任务保持、操炮或维修指令。
- 两名工人的矿点、建造落点、路线第一步和购买预算统一协调；不同矿点是优先偏好，不是唯一矿点也拒绝的硬规则。
- 为炮手交接留合法等待格，依据下一轮真实占位确认后换人，不能同时走进同一格，也不能同轮移动又开炮。
- 路径失效后先重算/绕路，再让空闲友军让路。允许的拆墙只针对可拆的非前六墙，不能拆中央前墙救一个短期路径问题。
- 白天没有可建、可买目标时应转采矿/卖矿；满包、无价、无路或来不及时给出明确等待原因，不无期限保留已经失效的购物计划。
- 工1无维修工具：第3夜起交战中退至基地安全位置做炮位候补并按条件使用基地券；获准额外外勤后转采矿/补给，不空守低血墙。
- 拓无剩余任务时，不在失效任务点徘徊；有采购和使用任务就处理，没有合法工作再返回安全待命。
- 等冷却、等模型/沙盒回执、等任务刷新且来不及切点、等确认交接都可以是合理等待，不能为了“每轮有动作”随意移动。

3. 炮台“完全无法防守”能动用多少生存资金；定义前只允许必要且合法的紧急恢复，不用模糊判断绕过预算。
4. 采购线路、剩余背包容量与实际持有人库存的适配；购买责任已确定，不引入拓代购后虚构转交。
5. 新怪、受击和断火可从目标仓库实际哪些观测/回执确认，冷却及伤害时序的兼容方式。

这些属于移植时核对真实接口和反馈的工程事项，不改变已定角色职责。没有证据时记录未知与明确回退，不能用推测覆盖已确认的行为。

## 12. 交付与回放验收清单

采用少量针对性边界回归，加上完整回放逐段检查；不以“测试数量多”代替观察行为。至少包含左右换边和未参与调参的地图/种子，记录源码版本与模拟假设。

| 场景 | 应观察到的结果 |
| --- | --- |
| 第1–2夜墙低于40%、炮台掉血 | 工1继续安全采矿，不被召回；工2/拓按岗位防守 |
| 第3夜中央墙39%，有匹配墙券及包 | 工1优先用券升级回血；没券则用包，3级墙不浪费券 |
| 墙40%或健康墙，持券且等级落后 | 不主动升级；白天也不升级，允许等级目标延后 |
| 白天关键墙39%且工1正在采矿 | 不因残血召回或补血，留夜间处理 |
| 白天关键前墙已经被打毁 | 工1优先准备材料、补建到1级，再恢复采矿 |
| 多墙低血 | 通常中央两墙优先，再正面两墙、前角两墙；同层低血优先 |
| 侧墙即将破口并危及工1、中央墙能撑住 | 先用维修包救侧墙，侧墙仍为1级 |
| 工1工具耗尽且安全窗口已满足 | 立即转采矿/补给，不持续对同墙发失败use |
| 拓正常操炮、怪只在墙外打墙 | 工2安全采矿，工1维护；不反复全员召回 |
| 三炮全部冷却一轮 | 不误报无人开火，不误召工2 |
| 主炮手死亡/离岗或真实断火 | 工2回防；第3夜起工2无法及时就位则工1接班 |
| 候补恢复 | 实际交接且3回合稳定后工2才离开，不与2回合计数混用 |
| 连续两回合安全与重复请求 | N基线、N+2放行；重复预览不加计数；新威胁撤销 |
| 类2可用/冷却/失败后再开放 | 优先类2，不可用则类1；失败不永久禁止 |
| 任务进行中基地告急 | 不主动移走拓；来不及的新任务根本不接 |
| 两点各3次周期结束 | 不再接耗尽点；错误提交不重复扣新机会；成功各自奖励 |
| 第9夜已有6包且可用 | 目标15，仅补9包；不每天再买15，也不多次预留同一笔钱 |
| 工1需要维修包、拓在商店或主炮位 | 默认由工1采购；不让拓代购后把库存算给工1，不为采购撤走唯一炮手 |
| 预算不足冲333 | 保留维修资金，延后升级，并记录具体缺口 |
| 基地低于25%、三炮未333且无基地券 | 不绕过维修和三炮预算抢买基地券；主炮手继续开炮 |
| 工1夜间无墙工具但有基地券 | 退至安全位置；先保证炮位覆盖，再在合法条件下使用基地券 |
| 黎明时工2仍在采矿且无更高优先级工作 | 继续采矿，不因夜末或换天回城；不存在-4/0回合强制召回 |
| 机器人将靠近采矿路线、另一条路线安全 | 绕行或换矿点继续工作，不触发无条件回城 |

回放应展示角色身份、当前岗位、目标、切换原因、库存及持有人、预算预留、炮手/候补、墙阈值、任务剩余机会与2/3回合计数。异常要能定位到“观测 → 决策 → 动作 → 下一轮结果”，成功和失败都保留，不能把本地回放当作官方PASS。
