# Issue 19：侧方基地的防御朝向校正

类别：策略优化；依据 R02/R03、用户补充 S02/S04 与 Issue #12/#19。不改官方几何、攻击、波次和计分。

## 问题和决定

旧策略按到地图中心的主导轴选正面。公开基地坐标 `(29,6)` 时，纵向距离略大于横向距离，优先北墙；本地固定来袭方向为西。真实候选包 HTTP 回放显示第一夜西面未封，工人阵亡后完好的炮台无人操控。

将冷启动先验改为：基地 footprint 完全位于地图中心列左侧时朝东、右侧时朝西；跨中心列时按纵向朝地图内部。使用基地 footprint，而不是角色 ID、红蓝颜色、种子或 `_demo`。既有炮台不迁移，出口连通性与建造合法性检查保留。

这是根据已有固定侧向来袭信息作出的策略选择，**不是官方刷新坐标，也不是已实现的自适应学习**。真实怪物改从其它方向来时仍可能选错；后续观测驱动的方向记忆需独立设计和验证。健康基地 watch 建议、任务中断政策均不在本改动范围。
