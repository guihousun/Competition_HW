## 官方口径核对

当前仓库官方接口文档 v1.0 §1.7 明确：`errorCode=2` 是“答案错误”，即 `submitAnswer` 提交的答案不正确或不完全正确；它不是 HTTP 超时、沙盒 `[TIMEOUT]`，也没有公开说明更细的数值范围映射。`value_mismatch` 是平台日志提供的细分标签，不能在没有题目原文、提交值和判题器回执时扩展解释成具体字段/范围错误。

因此本 Issue 可以确认：`errorCode=2` 含义固定为答案不正确或不完全正确；**不能仅凭它判断是缓存旧答案、格式错误、数值错误还是题目理解错误。**
