# 正式HTTP Agent与模拟器的分离验证

类别：模拟器/验证工具；R01/R07。根POST仍只返回官方字段，不直接等待外部API。

现有step(payload, commands)仍会运行内部规划、记账和预览，不能将它当成纯外部判题器。
新增显式external_response模式，仅验证并结算外部完整响应，透传其prompt/executeCmd供测试宿主处理。
不运行内部plan_for_state、消费回执或生成本地预览。模拟器仍按原有规则推进矿产、战斗和任务判题。
外部Agent维护自己的上下文；模拟器不伪造或同步该上下文，切换回自动模拟需明确从冷状态开始。

验收：外部采矿的独立结算、禁止内部决策的断言、公有观测→外部Agent→模型/虚拟沙盒→结算完整任务、
错误/混用响应拒绝。完整回归后用于真正启动压缩包的HTTP连续对局，记录每次延迟与p95/p99/max。
模型可用脚本固定响应以隔离HTTP开销，必须标明；正式入口不能将本地API时延算进回包时间。
5秒以上或请求超时判为失败。工具路径仍为虚拟沙盒，不在宿主机执行模型Shell。
