# 用户策略：单炮手三火炮与昼夜分工

来源：用户2026-09-21明确要求“一人三火炮”；进一步明确“第四天起晚上全员防守，白天和以前一样”。类别：策略优化与运行配置工具；规则依据R01/R02/R03/R04/R06/R07及任务书§4.1–4.7、接口§1–2。当前代码基线99933c6，原参赛包源码2296d9a。

## 实际行为合同

1. 新建三座rocket，一名存活工人轮流操作，绝不在同一轮操两炮。默认固定最低ID活工人；死亡才由另一活工人替补；先锋不作为常态第三炮手。使用官方cooldown与真实弹道，不预测未公开波次。
2. 布局优先保留同时邻接三炮的合法空格，炮手白天经已有后出口提前到位，夜间原地轮流开炮。允许内圈分成多个区域，但每个区域都必须能通往已有后出口；不再把整个内圈互通当作官方硬约束。没有安全共同位时才退回墙内短路径轮换；夜间已在内圈的炮手不得为换位绕到墙外，也不得增加炮手伪造“一人三炮”。布局根据己方基地求解，前沿位置优先级低于共同站位。当前本地几何下共同位在基地后侧，这一取舍须在真实地图核验。
3. 前三夜沿用安全任务/清场经济条件；从第4夜起先锋回防，另一工人维护城墙。第4天白天仍正常任务、采矿、交易、建设，没有按day>=4关闭白天任务。
4. 参数文件中前三天新武器升级目标默认为111、122、222，之后222；不是官方升级数值或当天完成保证，也不降级/拆已有武器。已持券、已派配送保持原承诺，新采购受当前报价、余额和完整返程限制。
5. 第4天起可由维修工准备2包备件。采购作为同一purchase槽的stock行程，买完直接返内圈，不白天立即耗光；库存仅计可维修工人，不能因先锋/固定炮手持包就停止维修工备货。
6. 夜间维修工在墙血<=55%时沿墙内路径维修，达到85%或库存耗尽/目标丢失则归位。固定炮手即使冷却也不被征调；维修反馈用真实库存下降与动作回执确认。当前路径堵塞不越墙，未到位不释放；preview不改真实记忆。夜间清场准备遵守显式配置，不能将当前无怪当未来永久无怪。
7. 后期受损前墙可优先用墙券；<=25%紧急墙允许备件采购先于新武器目标；基地<=40%触发既有紧急升级排序。所有阈值是策略参数，官方物品效果、价格/射程/计分不是调参项。
8. 共同炮位不作为其他角色普通回防的停车位；白天空闲占位者可经后出口让位，正在执行的任务、交易和维修不被抢占。夜间不能安全让位时不强迫出墙，原炮手可在当前墙内位置操作身边就绪炮，并记录共同位被阻挡的降级原因。
9. 黄昏只对闲置、未被任务或维修占用的角色进行通道让位；先让出当前占格，后续轮再让炮手通过，不假装同时穿过队友。炮手经公开合法路径回共同位优先于采购返程的余量检查；保留采购者返程归属，不因其逾期而删掉炮手的合法回防移动。白天可经观测到的其他合法开口绕行，并非只准走后门；夜间已在内圈的角色仍不出墙绕路。
