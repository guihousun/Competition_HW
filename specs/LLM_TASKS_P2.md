# P2 查询方法复用

状态：SkillLibrary组件原型已编写并通过独立测试；尚未接入团队Agent，不声明P2完成。
类别：策略优化/内部记忆；依据R07、任务书§5.3（查询不同城市，形成SOP），不改变官方规则。

## 原型合同

task_skills.SkillLibrary按owner隔离。只有同一任务代际中已验证、退出码0、未截断的文档读取和查询记录可以学习。
存储文档绝对路径、完整内容指纹和查询命令格式；所有历史参数值替换为<current-value>，不保存查询输出或答案。
当前原型支持已观测的python/python3绝对脚本入口及选项；不把内联代码或复合Shell猜成可泛化方法。

candidates(task_text)只返回可能相关的文档位置及“需要重新核对”状态，不提供可直接执行的旧命令。
hint(id,current_document)要求当前已验证文档与记录指纹完全相同，才提供查询格式提示；调用者仍须根据新题选择参数并实际读取新数据。
文档改版、未知路径、截断、失败、跨代际或跨owner的未验证资料一律不能提升为可复用方法。损坏存档显式降级。

“查询方法验证”只表示观察到文档一致且命令成功执行，不等于答案正确或官方判题PASS。提示词必须区分两者。

## 待完成集成与验收

1. 由队伍Agent持有方法库，作为独立长期方法记忆；不放到每题结束即清空的solver_notes中，不跨队共享私有上下文。
2. 仅接收共享router关联后的原文/工具证据。命令nonce包装必须剥离后再对文档原文取hash；截断或未知归属不学习。
3. 给模型提供候选文档位置；当前文档核对后再提供命令格式。不得自动执行未知来源的缓存步骤。
4. 同接口从北京换上海必须查询新数据、不能复用23等旧答案；同文档路径改参数名/接口版本必须拒绝旧格式并重新探索。
5. 固定对比无SOP/有SOP，同组新参数任务正确性不下降，并记录减少的发现步骤、模型调用与模拟回合。真实模型试验和确定性调度测试分开报告。
6. JSON运输、对局重置、队伍隔离、同名接口变更、失败命令、旧参数与输出不进入方法库存档，都需验证。

当前5项独立测试只证明存储/核验/脱敏参数合同；操作轮数减少和整局策略收益尚未验证。
