# 双炮操控、局部交战与战斗画面

2026-09-16，基线 96e4b4b。类别：策略优化、本地假设修正、UI 工具。

依据：DEVELOPMENT_RULES R01/R02/R04/R05/R06；任务书 §4.5、§4.7，接口 §2.2。
用户确认机器人主要进攻基地，只攻击附近角色。保持官方射程 3、伤害、冷却、墙体遮挡；
附近暂以射程 3 为本地交战半径，不能标为官方完整 AI。已有回放不重新结算。

1. 新建双火箭优先共享一个合法墙内操控格，激光不得占据该格；保持内圈连通、三名角色
   均有合法操控位，保留已有建筑。公共位不可达/被占用时退回普通分配。
2. 同一工人在共享位依次操控就绪火箭，每轮最多一炮；有修复/物品任务时让出操控。
   冷却仍为发射后 3 轮。第四夜起全员防守约定保持。
3. 开拓者夜间移动不得主动进入可见怪物未被墙遮挡的射程；遭遇近敌优先降低暴露。
   使用实际观测，不修改攻击数值或预知未来波次，不保证角色绝对存活。
4. 武器、城墙等级直接读取状态：三级外观分层，显示紧凑但可读的等级标记；升级成功才
   提示变化。回放跳转不得伪造升级事件。火箭飞行后爆炸，电磁炮显示实际路径光束；
   调试指令覆盖层不再把所有攻击画成贯穿光束。伤害数字只来自命中记录。
