# 新闻与多日传闻Agent接入

2026-09-15，类别：内部架构/策略优化；R01、R06、R07，任务书4.8/5.1/5.2。原文和官方数值未变。
状态：WorldAgent已接入实际采矿与宝藏行动，675项完整测试通过；连续多日对照与真实模型验收仍在后续阶段，不代表整体目标完成。

## 数据与调用

TeamAgent schema升至2，持有WorldAgent。COMPETITION_HW_WORLD_AGENT=on单独开启；COMPETITION_HW_TASK_AGENT=on同时开启完整认知协调。它们使用唯一LLMRouter和JudgeState，新闻与宝藏共享每天3次普通调用；不借自进化任务豁免增加普通额度。

每种主题最多保留12条公开原文，每条最多3000字符；来源以原文SHA256与首次观测回合登记。相同原文不因每轮重读而重新请求或重算相对日期。来源过长明确标记截断，不凭该截断资料批准结论。这是工程内存限制，不是官方题目长度限制；后续长文检索仍需补齐。

来源版本变化生成新提案；未发出的旧版本队列作废，已发出的旧回复按request归属接收，版本过期不进入当前结论。每版本最多实际发出两次；排队不扣次数，普通额度耗尽继续确定性游戏动作。

所有模型结论必须附sourceId与逐字quote。模型不得输出角色动作、任意价格数字或Shell。日期、地图范围、字段类型、枚举和证据均校验。模型推断不会升级为官方规则或真实环境证明。

## 新闻行动

结构化事件包含矿名、可开采/不可开采/未知、起止游戏日、价格方向和来源。只有同一资源当前日期的结论一致为不可开采时，策略才避开该矿；未知和相互矛盾事件不变成硬性禁采。已有库存仍可出售，交易始终读取当前vendorShopList，不把预测涨幅换算成自造价格。

## 宝藏行动

保留跨日地点、用品、开启时间的独立证据。条件缺失或不确定时不生成召唤；完整时交给原有路径、背包、商店、时间和队伍预算检查。完整显式格式的传闻可以走确定性解析，但含附加更正、越界或截断内容不走该捷径。

只有已实际发出的召唤才登记尝试。公开返回1/4标记已取走；2/3使旧假设失效，带原行动和反馈重新分析，防止无条件重复献祭。物品消耗仍由真实模拟器结算，模型解释不修改规则。

2026-09-15连续模拟补充：只等条件齐全再准备会错过窗口。已知地点/用品、时间未知时允许受控采购；保留三座武器、1000基地HP、25金币缓冲、正在执行的自进化任务和回防路径时间预算。仍不召唤。阈值属于策略，实际得分可能因绕路低于基线，见reports/llm-tasks-multiday。

## 证据与剩余验收

12项独立测试涵盖采矿改道与恢复、实时价格、不造涨幅、伪证拒绝、跨日JSON记忆、真实召唤动作、失败后停止重复献祭、库存检查、同日第四次请求被阻止、私有未来信息隔离、更正消息与损坏存档。

连续多日试验使用同图同阵营关闭/开启对照，脚本只根据公开传闻模拟模型回复。须报告宝藏是否实际结算、基地血量和总分；短程动作测试不替代该结果。再进行真实OpenRouter解释、长上下文、方法复用效率及完整1300轮留出验证后，才能验收整个目标。
