线条、血量与事件

升级与开火 建筑角标 1/2/3 表示真实等级：一级灰色、二级青色强化、三级金色重甲。火箭为橙色弹体与爆炸，电磁炮为蓝白穿透光束；目标圈是指令标记，不是伤害范围。伤害数字来自实际命中记录。

黄色虚线 下一轮准备提交的指令，不代表执行成功。在「显示图层」中开启。

青色实线 已执行移动的方向；攻击指令只显示目标圈。闪光和伤害数字来自已记录的战斗事件。

角色铭牌 紧凑两行：身份、#角色 ID，以及「生命当前值/上限 · 背包数量/容量」。字号不随地图缩小；完整明细在控制台单位卡里。背包数字是物品数量，不是等级或伤害。

任务时间条 开拓者执行任务时，铭牌多一行剩余轮数和一条细时间条，与控制台一致；这是倒计时，不是解题完成率。结算后另显示实际通过率。

昼夜底色 白天地面与地图外背景为亮色，黄昏偏暖，夜晚转为深蓝；颜色只来自当前回合的昼夜阶段，回放拖动时间轴会恢复对应色调。

血量条 绿 / 黄 / 红表示从健康到濒危。选中单位可查看具体血量、坐标与冷却。

时间轴色标 红色：失败或阵亡；绿色：任务 / 宝藏；橙色：波次或昼夜切换。一轮可能有多种事件，可用筛选定位。

射程框 选中炮台或开启「射程」后查看；表示攻击范围，不是移动路线或视野范围。

常用操作

观战 开始后自动推进；空格暂停 / 继续，← → 后退 / 前进一轮。

地图 拖动平移、滚轮缩放；点击角色卡放大定位，F 或「全图」恢复全景。

复盘 「回到开头」保留历史；「开始新对局」重新生成。「录像与复盘」可生成、打开和保存整场录像。

坐标 左下角为原点，x 向右、y 向上。图例只解释显示，不改变比赛规则。
