一、总策略

防守核心 策略

  • 默认三座武器都是 rocket，尽量由一个角色站在三炮公共操控位轮换开火。
  • 工人先保证炮台有人操作；开拓者完成任务且没有在途回执时，前 3 天夜间可以安全接管炮位。
  • 第 4 天起，夜间全员防守；工人负责炮台、维修和回防，开拓者不再为了普通任务离开防区。

基地与墙 策略

  • 墙按迎敌方向动态计算，左右阵营不写死蓝方坐标。
  • 前六堵墙优先：正中央两堵 → 前方两侧 → 前方拐角两堵。
  • 最后一排墙不新建、不追加常规升级；已有墙不会为了布局自动拆除。

经济目标 策略

  • 从第 1 天就允许三炮朝 3/3/3 升级；有钱时先补齐低等级，再冲三级。
  • 白天工人采矿、卖矿、买升级券和维修包，统一保留基地与炮台的必要预算。
  • 第 3 天起先为维修包和关键墙券预留资金，再考虑炮台升级；侧墙默认保持一级。

信息与Agent 分层

  • 常规移动、采矿、建造、操炮、维修由确定性策略执行。
  • LLM/Agent只处理任务题、新闻解释、宝藏线索和需要沙盒的认知工作。
  • 模型调用有上下文和日额度管理，不参与每一轮普通防守。

二、按时间推进

开局准备确定阵营与布局

读取当前 teamOur，而不是猜蓝方/红方。

布置三火炮、公共操控位、前六墙目标和安全通道。

第 1–3 天 · 白天发展经济与完成任务

两工人尽量去不同矿点，采矿→卖矿→买券/维修包。

开拓者处理任务和有依据的宝藏行程。

有预算就升级炮台和前六墙。

第 1–3 天 · 夜晚防守为主，安全时接管

工人保证三炮持续有人操作。

空闲且已完成任务的开拓者可安全交接炮位。

维修、战斗道具和回防优先；不建墙、不建炮。

第 4 天以后夜间全员防守

白天仍然采矿、交易、升级和备料。

夜晚工人守炮/修墙，开拓者回防；基地或前墙危险时立即救援。

只在确认清场后释放非战斗工作。

三、工1、工2、拓：当前职责与行为逻辑

工1
默认主工人
“工1/工2”按己方工人 ID 排序显示，页面保留初始及死亡成员，工1死亡不会把工2改名。白天两人共用建设和经济逻辑；夜间默认优先由最小存活 ID 的工人操炮，实际岗位还取决于位置和动作占用。
工2
默认副工人
白天同样参与补炮、采石、建墙和交易，不是固定只挖矿。夜间未担任炮手的工人可以携带维修包维护城墙；具体岗位以本轮分配为准。
拓
任务/接管
唯一可以领取和提交任务的角色。任务完成且没有模型/沙盒回执时，前 3 天夜间可接管公共炮位；第 4 天起夜间默认回防。

工1｜炮位与主建设 岗位可交接，名字不随岗位变

  • 白天：优先补建三炮、前六墙和中央墙；若防线允许，采矿、卖矿、买券。
  • 夜晚：优先站三炮公共操控位，负责持续开火；不因炮台冷却被临时派去远处。
  • 异常：任一存活工人生命值 ≤55，或已无存活工人时，会尝试让空闲拓接管；仍需满足任务已结束、无在途回执、路线和站位合法，不能保证当轮完成。

工2｜经济与维修 同样可以建设和操炮

  • 白天：也先补缺炮、采石建墙；防线具备后尽量与工1选择不同矿点。达到采矿批量目标、装载或时间条件时卖矿；可用金币与剩余路程允许才采购。
  • 夜晚：交战期间留在防区。第 3 天起，非炮手携维修包、目标可达时修墙：≤55% 开始，≥85% 或包用尽后返回原站位；紧急墙优先，其次中央两墙、其余前墙。
  • 空闲：白天未分配动作且背包未满时，再尝试可达资源；交战夜间没有合法维修或开火机会可以等待。清场确认后才释放外勤；当前仍可能因无路、缺钱或缺物品而等待。

拓｜任务与炮位接管 唯一任务角色

  • 白天：领取任务、自动探查任务文档、调用沙盒查询、根据反馈修正并提交答案；也可处理有证据的宝藏流程。
  • 夜晚：有进行中的任务或回执时保留任务上下文；任务完成后，前 3 天可安全接三炮。
  • 第 4 天起：交战夜间默认回防；紧急接管也必须先确认任务结束且无在途回执。清场确认后可恢复工作。两类自进化任务各3次机会耗尽后，不再尝试已失效的任务点，可参与防守和具备条件的宝藏流程。
共同约束：白天按到岗位的路径长度和入夜余量动态回防；两工人共用金币预留与落点协调，不是各花一份钱。交战夜间先保操炮，再安排非炮手修墙；连续 3 个完整安全回合确认清场后，三人重新评估可做的工作。拓不能采矿、建造或拆墙；工人不能领取和提交自进化任务。炮台冷却、等待任务回执、维修物品不足、无合法路径都可能表现为不移动，应结合控制台原因判断。

四、关键工作流

采矿与交易

观察可达矿点→两工人分开占点→背包接近目标→小贩卖矿→武器商店买券/道具

一个矿点耗尽、不可达或路线来不及时，会切换目标或回到安全站位，避免白天空转。

升级与维修

预算预留→生存储备 / 紧急墙→三炮 333 目标→中央两墙→前六墙→维修包按阈值使用

当前维修默认低于 55% 开始考虑，修到 85% 退出；低于 25% 进入紧急维修判断。

任务与长题

收到题目→有界定位并读文档→LLM / 沙盒查询→回执核对与证据记忆→提交答案

任务上下文与普通防守状态分开保存；每次请求仍只输出官方允许的动作。

路径冲突恢复

多格任务点 footprint→同轮落点协调→连续 3 轮停滞诊断→让路/绕行

允许时可拆除非前六墙开通道路，最多保留 2 个通路；不拆前六墙。

五、夜间清场例外

当前不是“看到场上没有怪就立刻离开”。先建立一次完整观测基线，再连续 3 个完整回合确认：

  • 没有新的我方目标机器人；
  • 己方角色、墙、炮台和基地没有观察到掉血或消失；
  • 路线不会穿过机器人危险区域。

确认后可采矿、卖矿、采购、使用维修物品或继续公开任务；夜间仍然不建墙/建炮。任何新怪、受击或观测缺失都会立即撤销资格并回防。
