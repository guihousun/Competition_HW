# Agent 测试候选说明

类别：Agent策略/测试集成；R01/R07协议、额度、任务豁免与平台沙盒权限保持不变。
固定codex/sgh用于公司回测；测试候选不表示官方或内网已通过，不自动关闭来源Issue。

参赛入口与本地入口统一默认开启TaskAgent。WorldAgent沿用该开关，提供新闻解释和多日宝藏记忆。
角色移动、资源交易和炮台控制仍由确定性策略及防御主管执行；模型不直接越过动作/预算检查。
正式root POST只输出roleCommandMap、prompt、executeCmd，不直接访问OpenRouter或等待网络模型。

可用环境变量回退/消融：

| 配置 | 行为 |
|---|---|
| 不设置 | TaskAgent和WorldAgent启用 |
| COMPETITION_HW_WORLD_AGENT=off | 仅关闭新闻/宝藏Agent，保留任务Agent |
| COMPETITION_HW_TASK_AGENT=off，WORLD_AGENT未设置或off | 关闭新Agent，保留原策略路径 |

所有普通模型请求仍共享每天3次额度。只有已确认的自进化任务可用任务内豁免；
没有回包、错误或额度耗尽时继续确定性行动，并有限重试/停止该认知步骤。

## 已验证与取舍

真实模型已验证三类固定查询任务、一次长文档检索及四日新闻/传闻解释；重复测试另行登记。
脚本模型完整对局覆盖四个种子、双方阵营和故障注入；各样本基地均存活，但全部能力
并非在每张地图上比仅任务模式得分更高。定向消融确认提前备料与新闻建议存在路径、经济和任务机会的交互。
一条“附近任务优先”的简化策略丢失原本可取得的宝藏且未改善差场景，已撤回，记录保留。
候选保留已验证的多日备料能力、完整预算/可达性/时限保护，供真实平台回测其收益。

默认开启是能力集成供测试的选择，不是“全面优于旧策略”或训练完成的声明。
仍需在真实地图/真实题目上回传请求、响应与结算，继续校准策略。未知固定刷新坐标、
完整官方沙盒和其他DEVELOPMENT_RULES.md差异均未因本地通过消失。
