# 迎敌防线与夜间分工

本次是策略优化，规则和官方源文未变。依据 DEVELOPMENT_RULES 的 R01/R02/R03/R04/R06、任务书 §4.1、§4.5–4.7 与补充 S03/S04。

## 当前候选行为

- 面向地图内侧设防。左侧基地先建右边，再建上、下两边靠右的半段；右侧基地镜像。最后补后半段，保留后方入口。
- 阵容为火箭—电磁炮—火箭。优先让相邻塔之间留空格并保留三个可达操控位；狭窄区域采用错位排列，不扩大现有建造区域。中间电磁炮朝向来袭方向。已有塔保留，不能保证旧阵地自动变成新形状。
- 有活怪、观测不足或刚入夜时，墙外工人回到规划墙环内，不能仅因能操作旁边炮台就在外面驻留；已在内侧的守炮移动不绕出墙环。入口被堵时不能瞬移，日志记录 `return_blocked`。
- **确认清场后保留外勤**：沿用有界采矿、买卖和维护，留人守炮；出现活怪即停止外勤回防。这不是预测下一波永远不会出现。
- 夜间前墙不高于满血的 70%，工人已在内侧相邻格且持有修复包，并有另一工人在内侧炮位时，一次允许一人使用 WallFixer，下一轮重新分配守炮。该道具一次回满墙 HP，不是持续修理，也不能修炮台。目前不是全自动巡墙跑动维修。
- 日间升级采购优先级：低于 60% HP 基地应急升级 → 一级武器升二级 → 二级武器升三级 → 健康基地 → 墙。武器必须建齐、资金/路径/白天往返时间等约束仍保留；已经买到的合法升级券先用，不丢弃重新采购。
- 新增变化才记录的 `worker_shelter` 日志：内圈、墙外 move/collect/use 等、回防被堵。状态仅描述位置/动作，**不表示完整墙体已建成或保证免伤**。

本地模拟器和参赛入口调用同一策略代码。已运行的服务需重启才能加载新代码，既有存档中的炮位不会自行搬迁。

## 后续对照：按防守余量释放角色去增收

2026-09-16 用户提出：前三天可以减少守炮人手，利用火箭冷却释放角色去安全区域；随后澄清不限定做题，也可以采矿、买卖。

这是待验证策略，不是已确认的官方难度保证，也不是本次候选默认行为。任务书 §五及动作权限要求自进化任务由**开拓者**领取，工人可执行采矿、交易、维护等外勤。

建议对照两名工人留守、开拓者赴安全己方任务点；火箭发射后有三轮冷却空窗，可以研究错峰操作，但每角色每轮仍只能操作一座武器。切换炮位需要合法移动和轮数；空出的激光输出、途中受击、任务中途离点导致结束，都要计入成本。

对照分工分三档：全员防守；任意两人防守、余下一人外勤；一人轮换操作火箭、其余外勤。优先验证第二档，不默认开拓者外出：若工人的矿石销售或升级券往返收益更高，可以由工人外勤、开拓者守炮。按官方角色权限枚举行动，外勤收益估算扣除行程、买卖动作数、损失火力和返程风险；按目前可见价格与库存计算，不使用未来波次或隐藏矿点。低一档防守只有在现有火力/墙体余量足够且安全返程可达时试验。

放行条件应依据当前观测：前墙/基地健康、两名工人在可用炮位、武器等级与冷却、实际怪物种类数量和距离、安全任务点及路线。日数只能作为试验范围，不能作为无条件放人依据。遇基地掉血、破墙、守卫死亡或高压怪接近则触发回防，明确记录中断任务的代价。

试验比较：基地存活率优先，其次任务积分/金币、有效炮击轮数、工人/开拓者死亡、任务中断率。使用真实日志回放及左右换边/留出种子；最终须在内网验证，不能仅因本地前三天过关便固定启用。
