# 清怪后的夜间工人安排

类别：策略优化（2026-09-13）。依据 R01/R02/R03/R06：任务书 §4.4 行为指令表、
§4.5 角色与建筑、§4.6.3 交易和物品；接口文档 §2 动作字段。
§4.4 对建造明确限定白天，对工人采集、交易、使用物品未列夜间禁用条件。
§4.7.1 描述白天生产、夜间防守的常见流程；本实现没有把描述扩展为所有生产动作的夜间禁令。
若官方后续补充夜间动作限制，应按新来源修正。官方原文不修改。

## 触发与退出

只在夜间、夜晚首轮之后，且观测明确包含 `robot.roles` 列表、没有存活机器人时启用。
缺失机器人字段不能推断成“已清场”。附近观察到敌方工人或开拓者也会停止夜间工作。
每轮重新检查；出现任何存活机器人（即便远处、不在炮射程内），立即交还原有防守规划。
这里的“立即”指当轮改发回防/攻击指令，不代表远处工人可以瞬移回炮位。

不读取未来波次、未公开敌方指令、种子或 `_demo` 来推断安全。

## 分工

- 两名工人都可原地使用背包中的药剂、升级券或修墙包，原地出售多余矿石，或在相邻商店采购确有用途的用品。
- 只允许ID排序最后的一名存活工人外出；另一名工人必须已经在其分配炮台的一格范围内。
  工人不足或守炮者尚未就位时，不派出采矿工人。
- 外出只选分配炮台四格范围内的矿点和行走落点。四格是内部策略阈值，不改变官方移动、射程或视野。
- 优先补石头到10个，给次日建设备料；有公开收购价时也可采集附近铁/铜，背包物品合计达到20个后停止额外采矿。
- 没有合适工作、背包满或超出工作范围时，回到原有炮位安排；不为制造动画而强制移动。

药剂用于血量不超过154的工人（70%阈值），修墙包用于不超过该等级70%血量的墙；
已有升级券按基地、炮台、围墙顺序选择相邻可升级目标。
同轮不重复维护同一建筑，也不反复购买工人已携带的同类用品。
采购接入全队预算预留，出售保留10个石头，尚未到账的出售收入不提前使用。

所有行为仍使用原有 `move/collect/buy/sell/use`，每角色每轮至多一条。
夜间不发出 `build`，开拓者仍由原有任务/宝藏/防守策略管理。

## 验证

手工预期测试见 `tests/test_nightwork.py`，包括清场采矿、守炮保留、出现新怪回防、
观测缺失、昼夜边界、死亡机器人、可见敌方接近、背包和距离限制、补给与预算、同目标维护去重。

```powershell
python -m unittest discover -s tests -v
python tools/check_nightwork.py --output reports/nightwork-new-run
```

配对实验只开关 `nightwork.plan`，其余代码与模拟器保持同一版本：
三火箭、压力3、种子1/7及事先指定的新留出6173，左右两侧，共12场，每场最多1300轮。
记录初始状态一致性、源码哈希、清场夜间工人的实际成功动作、基地血量、得分与失败。
不调用付费LLM，不连接内网。

结果见 [本轮报告](../reports/nightwork-20260913-final/REPORT.md)。

修正后重跑最终矩阵。6173是本轮预先指定的验证地图，重复验证不算新增独立样本。
