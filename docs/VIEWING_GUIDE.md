# 观战界面与交互更新

变更类别：**UI工具**。仅调整界面、呈现与回放控制，不修改比赛策略、规则或结算。
遵循 R01（调试界面不改变官方 POST）、R02（真实坐标和昼夜）、R04（射击呈现来自真实指令）、
R08（本地终局不冒充官方胜负）。固定刷怪点差异仍常驻提示，详见 `RULE_SUPPLEMENTS.md`。

## 最常用的三个流程

1. **看一场对局**：点击「开始模拟」或「开始观看对局」，自动创建并播放。
   参数收在「对局设置」，相同地图编号可复现相同布局。
2. **看懂战况**：地图上方显示金币、基地血量、本地分数和机器人数量；右侧说明当前昼夜阶段、
   剩余轮数、行动角色和刚发生的事件。「下一步」是预览，「刚刚发生」是已结算结果。
   点击角色卡会暂停并放大定位；「基地近景」跟随基地，「全图」恢复完整地图。
3. **复盘问题**：「录像与复盘」里生成/打开/保存录像，时间轴可后退、前进或定位事件。
   「回到开头」保留实时对局历史，先回看已记录的轮次，到达记录末尾后可继续模拟。
   要丢弃当前对局并重新生成，请点击「开始新对局」。

## 显示层级

- 地图左上常驻简明图例；「图例与操作说明」提供与地图同源绘制的角色、建筑、四类机器人、
  矿物、商店与任务点图标，以及箭头、射程、血量和时间轴标记说明。打开说明会暂停播放，
  Escape 可关闭；地图底部提示随实时播放、暂停、录像和单轮示例切换。

- 暂停/继续共用一个按钮，未开始或等待请求时按实际状态启停。
- 网格、射程、指令图层放在「显示图层」。下一轮预览箭头默认关闭；已执行图层保留。
- 基地、商店和任务点有固定字号的文字标识；默认移除夜间暗化遮罩以提高可读性。
  这只是画面亮度调整，不扩大策略观测，也不让被过滤的单位出现。
- JSON、规则表、双队对比与诊断在「调试面板」；初始收起，可通过顶栏或事件/详情入口打开。
- 弹出菜单支持点击外部和 Escape 关闭；控件有键盘焦点提示，页签标记选中状态。
- 小屏把战况栏移到地图下方，页面允许纵向滚动，防止地图被挤成一条。

## 相关修复与验证

- 指令箭头按单位 ID 找到真实起点；已执行移动使用事件记录中的出发位置，预览使用当前位置。
- 控制炮台的角色卡会显示“操控炮台开火”，而不是因指令以炮台 ID 为键而误报没有指令。
- 创建成功才自动播放，失败不会误播放旧对局；回到开头不会丢失已录历史。
- `test_viewer.py`、`test_replay.py` 均通过，包括上述箭头起点、昼夜解说、自动开始及保留历史回归。
- 本轮未调整模拟器，因此未重跑策略整场成绩基准，也不更新历史分数结论。
- 浏览器实测：一键开始并自动推进、暂停/继续、角色定位、详细字段展开、菜单 Escape 关闭、
  回到开头保留 85 轮记录；900 像素窗口页面宽度 885、430 像素窗口页面宽度 415，均无横向溢出。
