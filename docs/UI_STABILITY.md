# 双栏控制台与播放稳定性

类别：UI工具。2026-09-13。只修改网页与前端测试，不改变 R01–R08 的协议、策略、规则或模拟结算。

## 布局与交互

- 左侧约300像素为控制台，包含设置、播放控制、状态、角色卡和开发者工具，独立滚动。
- 右侧占据其余宽度和视口高度，保留地图、视图工具及紧凑时间轴。1440×900实测右侧1140像素，占79.2%。
- 1280×720窗口两栏高度为720像素；不再被旧短窗口样式撑成1790像素。控制按钮排列在左栏状态卡之前。
- 窄屏自动上下排列，游戏优先。430像素窗口实测文档宽度等于可用视口宽度，没有横向溢出。
- 同尺寸canvas设置不再反复清空缓冲区；角色卡按身份复用DOM节点，点击时解析当前角色对象。
- 普通回合请求与整场加载分离，不再每轮禁用/恢复整组按钮；暂停、缩放与查看设置可继续操作。
- 跳转输入保持到“跳转”/Enter或取消；输入框失焦、回合刷新不会覆盖草稿。JSON编辑同样保留未应用内容。
- 旧场景的迟到响应不覆盖当前视图；仍保留重复推进保护、LLM等待及错误提示。
- 时间轴标记恢复为10像素高、容器24像素，不再继承普通按钮36像素最小高度而溢出。
