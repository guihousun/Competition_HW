# LLM 通道补缺 Spec

2026-09-12；隔离分支 codex/gap-llm。输入为当前本地模拟器快照，远程 main 尚无完整游戏代码。
基线提交：fef12156c9057c1585284da817f9197763a174ec。
类别：官方接口实现修复（R01/R07，接口 §1.1/§1.7/§2）、本地适配 / UI工具。

验收：
1. 根 POST 透传 respond() 的 prompt / executeCmd，不直接访问外部模型。
2. Planner JSON 往返保存 pending 请求和已解析命令结果；回执只在后续回合消费。
3. 本地 DeepSeek 适配固定官方 HTTPS endpoint、deepseek-flash/max；只从服务端加载密钥，
   不复制到状态、前端、报告、源码或错误正文。拒绝 HTTP 重定向。
4. 显式启用的本地演示可调用真实模型；普通场景/批量基准默认不付费调用。
   相同回合重传不重复调用；请求期间不推进游戏；失败以独立状态报告，不伪造答案。
5. 增加一题标注本地夹具的运算任务，走实际 planner、prompt、llmResp、submitAnswer、结算链路。
   答案键只存在模拟器私有状态。沙盒命令仍不在宿主机任意执行。
6. UI 展示提供方、模型、启用情况和调用结果。独立手算用例/HTTP 回归/完整测试通过后再集成。
   最多做少量真实调用核验，不因重试循环产生无界费用。

未纳入：固定出生点坐标（未提供）、官方沙盒容器、未知任务判题数据、全部双队胜负差异。
本地 API 成功不等于官方平台认证；不自动合并或发布协议行为变更。
