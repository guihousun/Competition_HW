工1、工2、拓：三火炮分工策略最终说明

版本 v1 · 2026-09-22 · 这是迁移实施说明，当前只整理策略，不代表现有代码已经采用。

三座火箭工1：墙体维护工2：前期炮手 / 后期候补拓：任务 / 后期主炮手本地策略，不是官方 PASS
重要边界：官方规则、角色权限、动作额度、武器和物品价格不能被策略改写。本文中的第1–2夜经济例外、3回合候补释放、2回合清场放行、40%墙阈值和动态库存是团队策略；地图刷怪精确坐标、并列选敌和官方时序仍需真实观测核对。

1. 最终目标

在三火炮持续输出和基地生存的前提下，减少空转，让工1专注墙体，工2负责经济与候补，拓前期完成高成功率任务、后期采购并主操炮。

  • 第1–2夜允许工1直接安全采矿，不等待安全回合，也不因墙低血或炮台受击召回。
  • 第3夜起工1留守防区，拓完成任务并实际接炮后工2才外出采矿。
  • 第3夜起额外外勤需连续2个完整安全回合和路线检查；工2退出候补仍需3个稳定回合。
  • 已领取任务不因告急主动中断；通过“不接太晚的新任务”降低风险。

2. 角色职责

工1｜墙体维护负责人

  • 白天采矿、卖矿、备墙券和维修包，也参与基础建设。
  • 第1–2夜仍可直接安全采矿。
  • 第3夜起处理低于40%的关键墙：匹配升级券优先，没券才用维修包。
  • 前六墙顺序：中央最前两堵 → 前方另外两堵 → 前方拐角两堵；同组血量最低优先。
  • 工具用尽或无可执行券后，获准外勤时转采矿、卖矿或采购，不无限等待。

工2｜前期主炮手 / 第一候补

  • 白天采矿、卖矿、采购和使用炮券，尽量与工1选择不同矿点。
  • 拓尚未结束任务阶段时，夜间操控三炮。
  • 拓实际接班后可以采矿；怪在墙外但没有实际异常时不因“有怪”召回。
  • 炮手死亡、炮台掉血、无人操控或有目标连续一轮无合法开火时回炮候补。
  • 候补后要等实际接管、炮台稳定、连续3回合正常防守，才可再次外出。

拓｜前期任务 / 后期主炮手

  • 只能领取和提交任务；不能采矿、建墙或拆墙。
  • 自进化类2优先；不可用、冷却或来不及时才切类1。
  • 每类3次，成功有奖励，失败也消耗机会；机会不恢复。
  • 全部任务机会耗尽后，白天负责采购炮券、维修包和必要道具。
  • 任务阶段结束并完成交接后，夜间主操三炮。

4. 墙体与资金

墙体动作

  1. 低于40%才触发夜间处理；恰好40%不触发。
  2. 有匹配墙券时升级，因为升级回满血。
  3. 没有匹配券才用维修包；3级墙不浪费券。
  4. 健康墙夜间不升级；侧墙保持一级；最后一排不新建。
  5. 第1–2天不买墙券；第3天起白天按前六墙顺序推进。

5. 任务与截止线

类2优先→类2不可用才类1→成功独立奖励→机会耗尽后拓采购
  • 两类任务各3次；成功和失败结束都消耗一次，30回合冷却不会恢复机会。
  • 前两天优先任务，第三天后仍可继续，但只能在剩余时间覆盖到达、执行、提交、回防时接新题。
  • 任务一旦领取不主动中断；超时、离开范围、拓死亡或完成按实际官方条件结算。
  • GitCode Agent 可借鉴有界探查、批量读文档、上下文回灌、错误修正和成功后方法沉淀；不得复用旧题答案或TOKEN。

6. 夜间安全状态

工2候补释放：3回合

工2回到炮位后，必须等拓或其他健康角色完成实际接管，且连续3个完整回合炮台无受击、应开火时能正常开火，才能重新采矿。

额外外勤放行：2回合

第3夜起，基线回合后连续2个完整回合无新威胁、无我方HP下降/单位消失、无观测缺失，并且路线不进入怪物近战危险格，才放行额外采矿或采购。墙外有怪但只是被墙挡住、没有实际攻击，不自动触发工2回炮。

新怪、真实受击、炮位失控、路线失效或观测缺失会立即撤销外勤。冷却中的炮不算“断火”。

7. 三火炮升级

  • 默认三座均为火箭发射台，优先寻找合法公共操控位。
  • 当前等级最低优先；同级时中央/主要进攻覆盖优先。
  • 目标仍是争取第4天前333，但必须让位于维修库存和低血关键墙；资金不足可延后。
  • 炮台冷却、操控者位置和目标合法性必须按每轮实际观测判断，不能靠重复发送命令提高攻速。

8. 迁移到 GitCode 的验收重点

  1. 第1–2夜工1确实不因墙/炮台受击召回；第3夜起候补链生效。
  2. 拓任务未完成时工2操炮；拓接班后工2可采矿；炮台真正异常才回炮。
  3. 低于40%的墙使用升级券优先，工具用尽可释放工1。
  4. 两类任务各3次、失败消耗、成功分别奖励；动态截止线不接太晚的新题。
  5. 维修库存按夜数目标和当前报价预留；团队金币账与个人背包账不混淆。
  6. 回放记录岗位、持有人、库存、预算、触发原因、2/3回合计数和实际回执。
