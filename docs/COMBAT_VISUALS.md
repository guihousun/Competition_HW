# 看懂升级与双炮防守

2026-09-16。类别：UI 工具、策略优化、本地模型补充。依据 R01/R02/R04/R05/R06；
官方数值不变，怪物主要攻基地的补充见 `RULE_SUPPLEMENTS.md` S06。

## 页面怎么看

- 炮台与墙的角标 **1 / 2 / 3** 是状态中的实际等级。
- 一级灰色；二级增加青色加固层；三级增加金色装甲。墙也会增高，火箭发射管数量随等级变化。
- 相邻录像帧发生真实等级提升时，出现 `Lv.1 → 2` 等提示。买到升级券只是进入背包，
  还需在目标旁使用成功才升级；页面不会因为买券或金币增加而提前变色。
- 火箭显示橙色弹体、短尾焰及落点爆炸；电磁炮显示蓝白穿透光束。
  攻击指令覆盖层只画目标圈，不再把火箭指令画成激光。
- 目标圈不是爆炸范围；伤害数字只读取实际命中记录。演出时间不改变回合结算。
- 点“基地近景”观察等级和操控位置；暂停后逐轮前进/后退核对动作、冷却与伤害。

默认角色名牌仅显示“工/拓 + 完整 ID”，细条表示生命和任务进度；选中或悬停才展开
HP、背包及倒计时，完整资料始终保留在左侧控制台。

## 双炮与开拓者

新建炮位优先使两个火箭共享一个墙内空格，并确保内圈岗位相通。在这些条件满足后，
双火箭优先贴近来敌侧城墙内侧：左侧基地朝右，右侧基地镜像；电磁炮错位以留出公共格。一个工人站在该格轮换
操控火箭，另一个工人优先操作电磁炮。每轮仍只能操控一座武器，火箭发射后的 3 轮冷却不变。
修复、物品使用、被占位和旧布局不可达时采用普通分配，不拆掉已有炮台强行重排。
为保持可达性，电磁炮可能错开一格，阵容仍是两个火箭、一个电磁炮。

开拓者夜间会检查当前格与计划落点的可见风险，尽量避开没有墙遮挡的怪物射程。
这是保守的局部策略，不能保证任何地图都不阵亡。第四夜起全员防守的约定保持。

模拟器根据用户补充改为主要向基地推进，仅与附近角色交战。“附近”暂取 3 格，精确
寻敌规则仍待官方核验；没有降低攻击力或射程。历史录像重播不重新结算，新开/继续模拟
使用当前实现，旧模型得分不能直接算成新策略提升。

## 武器升级优先

防御采购按当前商店报价预留下一张有效武器升级券的金币。钱不足时继续攒钱，不用这笔
预算购买便宜城墙券；昼夜采购使用相同规则。已持有的券仍可使用，紧急基地升级、维修和
生命物品保留原来的触发条件。报价缺失时不臆造价格；有报价的武器升级尚未完成时，普通墙/基地升级券暂停新购；其他战斗物品只使用预留外的余款。

三炮成型且预算足够时，升级行程可从清晨出发；按实际去程、购买、回程、使用计算，
必须在入夜前留下 3 轮缓冲。普通工作的提前回防时点不再一刀切打断这个有界行程。
任务/宝藏消费仍由其原有仲裁处理，本次没有改写全部经济策略。
