# 规则补充登记

来源：用户在本项目对话中于 2026-09-12 提供的赛题规则补充。属于用户转述，尚无新增官方文件
或平台回放作为附件。原始 `任务书.md` / `接口文档.md` 保持原样；本文件单独记录补充及实现影响。

## S01 — 围墙与己方子弹（关联 R04；任务书 §4.5.4）

用户原文：**“围棋不会阻挡己方的子弹”**。

当前按“围墙不会阻挡己方子弹”理解，“围棋”疑为笔误，已请求确认。
不据此推导敌方围墙、其他建筑对弹道的影响；也不改变围墙对角色/机器人的移动阻挡。

现状：模拟器将机器人作为加特林/电磁炮的弹道命中对象，己方墙不截断弹道；火箭也不受墙阻挡。
新增手算布局回归：炮 (10,10)、墙 (11,10)、目标机器人 (12,10)，操控者 (10,11)。
一级加特林/电磁炮命中 10，火箭命中 20；墙不能使命中失效。本次不改变弹道实现。

## S02 — 随夜数增长的机器人数量（关联 R05；任务书 §4.7.3）

用户原文：**“机器人数量会随夜数增加而增加”**。

该方向与现有任务书一致。当前正常空场下基础波次数量为“夜数 × 本地压力 + 1”；
这只是本地生成公式，不是官方数量。增长公式、每夜类型比例及召唤令造成的额外数量另行区分。
回归覆盖十夜、两侧、三种压力，验证基础波次总数递增；不声称验证了官方波次数值。

## S03 — 固定机器人刷新点（关联 R05；任务书 §4.7.3 的补充）

用户原文：**“机器人的刷新点是固定的，不会从四面八方刷”**。

新增行为约束：不得每夜围绕基地重新随机选取四面八方的出生位置。
当前 `scenarios.prepare_round()` 在离基地 8–13 格的环带重新随机抽样，**与补充冲突，属于非合规近似**，
不能继续仅以“官方未规定，所以本地假设”解释。

仍待确认：固定点的数量/坐标、是否随地图变化、双方各自的刷新点、点被占用及一批多机器人
如何落位。知道“固定”不等于知道具体位置，不能把自行选择的一组坐标标为官方位置。
本轮先登记冲突并在前端规则面板显式提示，等待位置说明后修复生成器。

## 迁移与验证边界

- 本次变更类别：规则依据登记 / UI工具 / 回归测试；没有调整策略和刷怪算法。
- 历史录像和基准仍保留，但其中全向随机刷怪不能作为符合 S03 的证据；不会重算或改写旧录像。
- 后续实现固定刷新点时必须更新模拟器版本证据，补测试“不同夜沿用固定点、点位不泄漏到策略、
  两侧归属和占用处理”；数量增长公式仍须保留本地假设标签。
- 公司内网平台尚未接入；上述核验仅针对本地代码。
