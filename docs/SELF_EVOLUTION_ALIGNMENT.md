# 自进化任务与中等强度策略实验对齐

本页把 Issue #21、#23、#24、#27、#28、#42–#46 的高置信观察接入本地模拟器。Issue 中的公司日志是行为证据，不替代任务书和接口文档；没有把对手 Bot 的 `ASSUMED/UNKNOWN` 参数写成官方规则。

## 已对齐的任务生命周期

新建模拟世界使用 `observed-local-v2` 任务规则：两个己方任务点各有 3 次有限机会，任务结束后消耗 1 次机会；30 回合冷却只恢复“可领取”状态，不恢复已消耗机会；默认元数据是 15 回合超时、80 分、80 金币。这些默认值来自 Issue #21/#23/#24 的实机公开记录和用户确认。旧录像或旧任务夹具没有规则元数据时按 `legacy-local-v1` 读取，不能在载入时静默改变剩余机会。

任务内容仍是本地夹具。真实平台中高置信的两类流程是：

1. 自进化类1通常是 API 查询：开拓者领取任务，读取任务文件和 `API_DOCS.md`，依据当前回执确定鉴权、参数和分页，执行查询并按当前题文提交 JSON。
2. 自进化类2通常是工程修复：读取 `spec.md` 与 `check`，在沙盒工作区修改文件，执行 `check`，只提交当前任务成功回执返回的 TOKEN。

两类任务都必须保留 `acceptTask → executeCmd/prompt → submitAnswer` 的关联链。`submitted`、`official_success_confirmed`、`value_mismatch`、`timeout` 和 `task_disappeared` 是不同状态；没有官方判题回执时不能把“已提交”改成“失败”或“成功”。

## 当前脚本策略

开拓者是唯一的任务角色。白天先判断任务点有效性、到达时间和剩余 15 回合预算；任务链不能让工人停止采矿、卖矿、建墙或升级。任务进行中，开拓者保持任务点一格范围，两个工人继续承担经济/建设分工。第 4 天夜间开始按用户策略全员防守；任务尚未提交时，回防会留下“中断任务”记录，不伪造结果。

夜间机器人以基地为主目标。机器人与角色切比雪夫距离大于 3 格时不改变原路径；距离 3 内可按本地并列规则交战。隔墙时先打路径第一面墙。策略层仍可使用 4 格作为攻击距离加一格移动余量的安全缓冲，但 4 格不能进入模拟器的机器人寻敌半径。

## 独立手动实验

`tools/manual_strategy_lab.py` 提供只读观测驱动的 `init / observe / step / run` 流程。每个实验目录保存冻结源码指纹、公共观测、动作、执行回执和摘要哈希；处理器只接收 `scenarios.observation()` 投影，不接触 `_demo`、未来波次、答案或沙盒私有数据。默认实验身份是：`observed-seven-days`、`attack-map-observed-v1`、中等本地压力、开发种子 311、留出种子 2029，红蓝两侧各一组。它是实验工具，不是参赛入口，也不声称官方通过。

8 路实验应分别记录：基地最低血量、终局血量、任务提交/确认/超时分类、攻击回合、空转回合、动作失败、武器等级、墙体损伤和金币/升级购买。已完成的八路中，稳定共识是“公共三炮位 + 冷却门控 + 两工人分工 + 任务机会耗尽后开拓者接炮”；负例显示失败目标黑名单、白天/夜间建造门控和升级购买承诺仍是必要条件。先在同一难度下比较炮位与工人分工，再把共识转成 `strategy.json` 参数；不能用单个种子总分调参。

当前可执行的泛化策略优先级是：2 rocket + 1 railgun；三座炮尽量放在迎敌前墙内侧并留一个公共操控位，当前代码已把公共位从“三火箭”泛化为“配置中的三座武器”；前四道墙和前方中间两道墙优先升级/维修，最后一排不主动新建；前三夜允许一名角色做安全经济或任务，遇到基地/前墙受损立即回防；第 4 夜起全员守炮/修墙。地图、阵营、出生点和商店位置一律从当前请求读取，不能按蓝方坐标或角色 ID 推断。
