# 怪物寻敌边界补充（2026-09-21）

来源：用户对真实比赛行为的补充，非新增官方原文。关联 R02/R05、任务书4.7、RULE_SUPPLEMENTS S06。

“怪物始终朝基地进攻，只要我方单位在怪物4格外他就不会偏移原来的路径。”

- 默认进攻目标是基地；我方角色与怪物切比雪夫距离大于4时，不因该角色改变攻基地路线。
- 这没有确认距离等于4或更近时必定追击、具体目标优先级或寻路并列选择，不能推断为全图追人。
- 寻敌/偏航范围与官方攻击射程3分开；不能把攻击范围改成4。
- 仍有进攻我方基地的怪物时，即使工人在4格外，也不算清场。清场工作避让怪物4格区域，接近危险当轮撤销并回防。
- 当前本地模拟器S06旧近身半径3需要另核对并做距离4/5及隔墙回归；本文件登记补充，不宣称模拟器已完全实现真实寻敌。
